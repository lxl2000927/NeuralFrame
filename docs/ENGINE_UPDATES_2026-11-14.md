本轮为调试更新，不生成发行包。原有游戏配置保持独立，已有引擎不会因打开页面、检查更新或普通参数调整而自动升级。

组件页「检查更新」读取原仓库 Releases，保留已有约 5 分钟冷却及服务端限流处理。新的 Encore 来源会使旧来源缓存失效，下一次检查重新取得版本。检查仅发现版本；下载入库、应用到游戏是后续独立步骤。

`engine-packages.js` 按已确认的 ZIP / DLL 指纹登记适配能力，实际选择时重新校验文件、大小、64 位 PE 和组件角色。候选发布版本名称、社区别名或文件名不能授予应用权限。未知新版可以下载留存，界面说明等待适配。推荐和已适配历史版本由游戏路线应用，不能通过通用 DLL 替换绕过路线限制。

## 游戏页行为

- 引擎版本区分别展示现装版本、推荐版本、上次检查的上游最新版本。`undefined` 表示保留现装（新安装使用推荐），空字符串表示明确选择推荐，包 ID 表示用户选择的库内版本。读取状态不会改变该选择。
- 鸣潮高级参数包括 Model A/B/C、结构强度、色调强度、人物遮罩和人物强度。诊断日志需要支持该能力的引擎，单独写入 `RTX40MFG-UI.ini` 的 `[Diagnostics] Logging`，不混入控制 JSON。
- NR 重新应用保留用户外观调校；切换硬件档位只调整该档位负责的资源/处理参数。显式「重置神经渲染调校」通过预览后才恢复适配默认值，未知字段保留。普通 RenoDX 单遍路线仍执行自身兼容限制。
- Encore 2.4.1 支持逐遍 `inherit / before-sr / after-sr / present`。原生 DLSS SR 自定义比例为 33–100%，2.3.0 为 50–100%；NR 工作分辨率比例是另一项设置。旧版不支持的活动配置会阻止降级，不静默忽略或改值。无原生 SR 时附加 DLSS 继续使用游戏分辨率 / DLAA。
- 版本、参数和重置均属于草稿，点击预览后再确认。鸣潮仅应用补帧不会提交待应用的 NR 外观参数。Encore 草稿按游戏及 EXE 保存，切换目标不串用设置。

## 文件与配置保护

鸣潮保持 `version.dll` 独立加载，不替换启动器校验的 DLSS / Streamline。无官服资源清单的渠道保留严格的附加文件范围；有清单但清单损坏或无法读取时不会降级为宽松路径。已识别的 RTXManager 加载器与归属收据成对处理，失败回滚、原字节还原及外部后续修改保护仍生效。

Encore 保留 JSONC 注释、未知字段和游戏内调校，仅更新受支持的页面参数。仍限制首批没有原生 FG 的游戏，不为鸣潮切换此路线。已部署不可变文件被其他工具修改时停止操作，不用新推荐版本悄悄覆盖。

MFG 原版 1.7.1 ZIP 只有 DLL，许可证作为单独内置小组件准备。许可原文在 `assets/licenses/`，准备脚本核对 SHA 后恢复 bootstrap。Encore 保留原作者的第三方声明。具体文件指纹由代码清单维护。
