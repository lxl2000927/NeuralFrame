# NeuralFrame 0.1.0 第一轮验证

日期：2026-11-06。基线：Enhanced 0.1.8，`39efdbf916f9f13bdef8680f13b4c036e2548214`。

## 设计对照

主要尺寸来源为用户提供的 NVIDIA App 前端拆解与 UI 布局规格。生成的 `game-settings-concept.png`（1586×992）用于整体方向，精确尺寸服从规格；页面由真实 DOM、控件和游戏数据构成，没有把概念图充当界面。

| 对照点 | 实现与实际检查 |
| --- | --- |
| 桌面框架 | 30px 标题栏、56px 页头、80px 导航；可展开到 256px。固定区域与内容滚动分离。 |
| 游戏列表 | 64px 行高、48px 封面；常规宽度 290px，窄窗口收紧。长名称省略，不挤压右侧。 |
| 游戏身份 | 真实封面、标题、平台、目录与启动操作，已检查鸣潮和星穹铁道。修正封面元数据对象误当字符串的问题。 |
| 配置层级 | 神经渲染、模型、倍率和档位优先；高级选项折叠，文件版本与运行证据分标签。 |
| 设置行 | 48px 基础行高，长说明允许增长；选择框限制宽度。窄窗口没有页面或设置行横向溢出。 |
| 操作区 | 底部撤销/预览并应用固定；未修改时禁用。切换游戏保留各自草稿。 |
| 色彩与文字 | 深色 #191919 / #222 / #292，绿色 #8bd529；共享浅色主题。系统中文字体和 Lucide 图标。 |
| 品牌 | 实际生成 N / 视频帧标志替换概念图里的简化 N，程序标题、EXE 元数据和安装图标为 NeuralFrame。 |

有意保留的差异：概念图中的样例标题、版本和数值替换为真实库；已关闭的功能仍显示关闭；没有运行证据时不显示已生效。生成概念图不能覆盖这些数据规则。

实际截图分别检查 1440×900 和 960×700 CSS 逻辑像素窗口。当前 Windows 为 150% 显示缩放，后者客户端宽度会舍入为 961 CSS 像素；测试只容许 1px 原生舍入，不容许被更大的最小宽度限制。

内置浏览器入口因“failed to write kernel assets / 系统找不到指定的路径”未能启动，改用 Playwright Electron 操作实际桌面程序。已查看实际截图与概念图，完成上表对照。截图与机器特定日志保存在本机交付目录，未提交用户配置或游戏列表。

## 自动化结果

- 核心回归：385 项，383 通过，0 失败，2 项原有跳过。
- 新前端配置规则：7 项全部通过；涵盖关闭值、只修改一个功能、无效值拒绝与未修改时禁止应用。
- 打包程序 UI：读取 9 款真实游戏；鸣潮和星穹铁道详情、组件清单、运行诊断读取、草稿切换、撤销、导航、深浅主题与窄窗口溢出检查通过，无捕获的页面脚本错误。
- 模拟后端的实际 UI 流程：取消组件准备、取消预览、携带确认令牌应用、复用已准备缓存全部通过；只修改 MFG 时未发送 NR 修改。
- 便携包装：连续启动使用独立解压目录；第二实例退出后第一实例的 F8 资源仍完整；152 个解压文件与构建目录哈希完全一致；两实例退出后临时解压目录清理完成。
- 配套组件迁移：14 个档案均核对远端文件大小和 SHA-256。
- TypeScript、前端生产构建、bootstrap 校验和 Windows 双格式打包通过。

## 性能测量边界

便携包装启动到 Electron Node 探针和 F8 资源就绪分别为 2234ms、2225ms；不包含渲染器和游戏扫描。打包 UI 从启动到首款游戏设置就绪约 9.2 秒，使用隔离配置副本。没有同条件旧版对照，因此不宣称本轮整体启动速度提升了某个百分比。

发行包仍仅携带约 2.7MB bootstrap 与 F8 桥接，大型运行库保持按需获取。便携 EXE 约 113.6MiB，安装包约 80.4MiB；Electron 本身仍随包分发。

## 验证范围与后续

本轮完成桌面外壳、配置状态和现有服务接入。未改写原生 C++ 渲染核心，未在实际游戏中安装本轮构建或验证画质、输入延迟和输出 FPS。开发验证未应用修改到真实游戏目录。

下一轮继续拆分主进程服务和插件能力描述；原生 F8 绘制与供应商特定参数可独立迭代。旧渲染器保留为迁移参考，但主窗口不再加载它。
