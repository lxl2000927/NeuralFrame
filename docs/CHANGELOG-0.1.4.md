# 0.1.4 恢复 Enhanced 原版管理面板结构

对照原始 Enhanced 2.3.0 安装包中的 `enhanced-ui.js` 与 `enhanced-ui.css`，恢复神经渲染管理和多帧生成管理两张卡片的原版结构。

- 按原版顺序展示标题与状态、信息列表、模式或倍率、模型或输入策略、说明和应用按钮。
- 移除这两张卡片内部新增的折叠重排，恢复标签在左、数值在右的信息行，以及原版字体、间距和控件样式。
- 下拉选项显示完整名称；窄窗口中限制控件宽度，并通过悬停提示提供完整文字。保留长文本换行和防溢出修复。
- 继续使用汉化、真实模型文件识别、运行时检测、版本选择、锁定与回滚功能；选择控件的保存值不变。
- 0.1.3 的紧凑顶部工具栏、DX12 标签与卡片操作按钮排列继续保留。

## 验证

- 实际 Electron 渲染器验证两个管理器的六段结构和顺序与原版一致。
- 覆盖独立档位页和游戏详情页、两种风格、明暗主题、800–1500 像素窗口及 125% 缩放；检查控件边界、完整选项提示和左右对齐。
- 模型库、运行时检测、运行库与输入策略选择、倍率提交、版本锁定和变更预览交互检查通过。
- 验证使用隔离用户目录和模拟游戏数据，没有修改游戏文件。
