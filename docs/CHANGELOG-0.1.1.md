# 0.1.1 修复说明

- 历史页新增“清除历史记录”及确认框；仅清除操作记录，保留游戏备份、版本锁定与回滚数据。重开页面或重启软件不会从旧备份重新导入已清除记录。

- 移除设置中的社区通知和社区个人资料入口；未配置开发社区服务时，不再为旧的启用记录启动通知轮询。
- 修复便携版重复启动共用临时解压目录的问题，避免第二个实例退出后导致正在运行的管理器提示缺少 F8 面板插件。
- 修复运行时检测复选框显示文本光标的问题，并统一勾选类控件的鼠标样式。
- 神经模型文件库显示本地可用数量与未导入记录，新增“获取更多神经模型”入口，直达组件库的神经模型筛选。
- 返回档位页面时重新读取模型库，显示刚下载或导入的模型；软件更新按钮改为明确的“检查软件更新”。

随包神经模型仍为一个不同的 310.8.SF-v2 文件。上游目录中的 310.9.16-oct2026 使用相同 SHA-256，不应被算作第二个模型。DLSS SR / FG 运行库与神经模型分别管理，版本号不能混为一谈。

本次修改不更换游戏中的运行库、补帧插件或参数。版本锁定、变更预览、回滚和已适配的中文面板保留。
