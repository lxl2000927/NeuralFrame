# 功能与操作指南

从这里完成一次游戏配置，或按左侧导航查找功能。需要确认某个文件的发布者或某个数值的含义时，可直接转到[组件来源与用途](COMPONENTS.md)或[参数手册](PARAMETERS.md)。

## 找游戏与检查兼容性

- **首页 → 扫描游戏库** 会发现可识别的本机游戏。可搜索、按平台分组、更换封面或隐藏游戏。要找回隐藏项，进入「设置 → 游戏库与扫描 → 已隐藏的游戏」。
- **游戏 → 添加游戏** 用来选单个游戏目录；**添加扫描文件夹** 用来长期扫描整个库。商店不同或路径不同的副本要分别配置。每个游戏若有多个 EXE，优先核对实际进入场景的程序。
- **游戏 → 批量扫描** 在部署前检查多款游戏的位数、API、已识别输入和候选路线。可导出 JSON 或 CSV，也可保留未完成的报告。「待确认」的条目适合到游戏详情检查 EXE 或图形 API。
- **画质与补帧 → 更多操作 → 重新检测文件** 会重新检查当前游戏。游戏升级、改用 DX12 启动或装入新的宿主后，可用它更新识别结果。联网游戏和带反作弊的程序按游戏方规则操作；部分路线会直接阻止部署。

## 配置与应用

| 游戏页入口 | 用途 | 操作后看哪里 |
| --- | --- | --- |
| 安装与运行环境 | 核对 EXE、位数、API、渲染后端、安装方式和已检测文件。没有 DLSS 时，页面会按游戏实际输入列出其他路线。 | 选择路线后先点「预览并应用安装方式」，核对目标目录和文件。 |
| 硬件档位、神经渲染 | 按 GPU 与显存选择工作分辨率和工作集，选择模型、运行库，或只应用 NR 设置。 | 查看模型的架构匹配、安装状态与运行诊断。[硬件与模型参数](PARAMETERS.md#硬件档位与神经渲染) |
| 多帧生成 | 选择当前游戏允许的引擎，以及由这个引擎管理的倍率或输入策略。 | 按界面提示重启，到游戏内启用对应输入，再查看本次会话的插件读数。[补帧参数](PARAMETERS.md#帧生成) |
| 配置预设 | 命名并保存当前路线的配置，供本游戏重用、导入或导出。预设记录可由桌面管理的参数和组件选择。 | 载入后先生成草稿，可撤销；核对预览后才写入游戏。 |
| 组件与版本 | 查看当前游戏的推荐组件组合、磁盘文件和已指定的版本。 | 点「配置组合」到「画质与补帧」选择功能，预览时按需准备组件。要指定单个版本，展开「自定义组件版本」，选择与游戏文件匹配的已入库版本，再预览变更。组合稳定后可「锁定当前组合」。 |

**例：Radeon 上某款 DX12 游戏只有 FSR 3.1 超分。** 在安装环境选择实际的 64 位 EXE；若页面列出独立 XeMFG，先准备 Intel 运行库与 MFG 插件，再预览部署。进入游戏开启 FSR 3.1 超分，关闭游戏自带的 FSR 或 XeFG 帧生成，按 Backspace 查看 XeMFG 是否读到输入。已有兼容 OptiScaler 宿主时，改到对应宿主菜单查看输出。[按 API 和宿主选路线](GAME-ROUTES.md)

## 下载、入库与历史版本

| 入口 | 用途 |
| --- | --- |
| 组件 → 检查更新 | 从配置的发布源读取版本。展开「历史版本」查看同一组件的其他构建，点一行比较版本说明、适配状态和文件指纹。若遇到 GitHub 限流，可根据页面给出的时间再次检查。 |
| 下载入库 / 导入 | 为本机组件库准备发布包、单个 DLL 或插件。导入时先选组件类型，再选文件。进入对应游戏的「组件与版本」选择要应用的版本。 |
| 下载源设置 | 无镜像时直连 GitHub。填写自定义镜像前缀后选择「GitHub 优先」或「镜像优先」，首选源失败时回退。文件身份仍依官方元数据和本版固定清单核对。 |
| 标题栏 → 下载队列 | 查看正在下载的文件、进度、等待项和失败原因。下载阶段暂停会保留可续传的数据，「取消并清理」会删除该任务的临时分段。 |
| 组件 → 缓存管理 | 查看占用并清理未引用、可重新下载的版本和临时文件。手动导入的文件、内置组件、游戏选中版本和恢复备份受到保护。 |
| 附加组件 | 添加自己的 `.addon` 或 `.addon64`，填写名称、标签与说明。同名文件一次可启用一个；下次通过 64 位「原生 DLSS + ReShade」安装时附带。移除条目会保留原文件。 |

## 游戏内面板

| 在哪里打开 | 什么时候用 |
| --- | --- |
| **F7 性能监控** | 在「叠加层」选择游戏和 EXE，可预览隐藏、精简、详细三种模式和四个浮窗位置。支持 F7 插件的游戏可安装并保存设置，游戏中按 F7 切换模式、按 Home 调整位置。鸣潮使用独立加载路线，目前仅支持页面预览。可导出 32 或 64 位插件。 |
| **Home 原始菜单** | 在适配的 ReShade 路线打开完整菜单。加载配套 RenoDX 后，可使用中文单遍调校和四组预设。 |
| **F8 紧凑面板** | 在「叠加层」启用「随支持的安装路线添加内置面板」，应用到游戏并保持管理器运行。按默认 F8 查看 DLSS、Feeder、着色器和连接状态。游戏中的控件按实际加载的插件开放。 |
| **Insert / Backspace** | Insert 用于对应路线的 OptiScaler 或 Encore 自带菜单，独立 XeMFG 默认用 Backspace 查看输入与运行状态。这些菜单由各自的组件提供。 |

叠加层页可预览或自定义 F8 配色、更换快捷键、管理面板插件，以及查看本地服务与游戏连接。外观预览中的滑块演示操作方式。要查看当前游戏的实际数值，请打开游戏内面板。[F7 读数与 F8 实时参数](PARAMETERS.md#f7-监控与-f8-实时控制)

## 运行诊断、回滚与恢复

| 遇到的情况 | 去哪里看、怎么处理 |
| --- | --- |
| 已经装好，实际画面看不出变化 | 进入实际游戏场景，在「游戏 → 运行诊断」点「立即检测」，需要连续观察时开启自动检测。先看正在运行的 EXE，再看进程加载的模块、插件日志和会话时间。 |
| 已选 3×，不知道是否生效 | 比较同一会话的基础帧率和插件报告的输出帧率，以及日志记录的有效倍率。只有已保存的设置、磁盘文件或过期采样时，仍缺少本次运行的倍率证据。 |
| 想复查一次操作或报告问题 | 「历史」记录操作时间、类别与文件变更。游戏页可导出诊断报告。兼容性页的 1080p 显存数据是估算值，实际波动可在 F7 查看。 |
| 刚改好草稿，还没确认 | 点「撤销」丢弃待应用的修改。要撤回已经写入的组件变更，应关闭游戏，再在「组件与版本」使用回滚。 |
| 想完整卸载一款游戏的插件 | 关闭游戏，在「更多操作 → 一键卸载并恢复」使用对应游戏目录中的 `_DLSS5_Backup` 还原。若同名文件已被其他工具改动，先阅读冲突提示并保留备份。 |

## 桌面设置与数据

「设置」可查看物理显卡、显存和显示器，设置简体中文或 English、主题、12–18 px 正文字号、托盘行为和窗口位置。**界面兼容模式**会在重启管理器后关闭桌面界面的硬件加速，适用于管理器窗口出现残影时。

扫描目录、排除目录、按平台分组和自动扫描其他磁盘控制游戏发现范围。用户设置、组件库和索引位于 %APPDATA% 的 `dlss5-swapper-enhanced` 目录，原始文件备份存放在各自游戏目录。

单独清理组件缓存请前往「组件 → 缓存管理」。在「设置 → 数据与缓存」选择「清理缓存并恢复初始状态」，会同时清理可释放的组件缓存、重置管理器设置和游戏库索引，默认保留游戏部署。手动导入的组件、回滚备份、操作历史和叠加层配置会保留。

卸载管理器前想一并撤销部署，可在重置选项中勾选「同时还原所有已部署游戏」。预览会列出有安装记录的游戏，包括单独安装过叠加层的游戏。确认后，管理器逐个恢复原文件并移除部署的组件。游戏离线、备份损坏或文件在预览后发生变化时，界面会列出需要处理的游戏，并保留缓存和索引供重试。

在「设置 → 软件更新」可核对当前版本、检查更新和查看版本说明。自 0.1.4 起，Windows x64 可在应用内下载更新，会按运行方式选择安装包或便携包，核对大小和 SHA-256 后保存到系统下载文件夹的 `NeuralFrame` 子目录。安装版可打开安装程序，便携版可定位到新版文件。0.1.3 需要从发行页手动下载。Linux AppImage 可下载、重启安装和恢复上一版本。[各平台构建方式](BUILDING.md)
