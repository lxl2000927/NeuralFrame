- 神经渲染、多帧生成保留上游字段和操作区域顺序；兼容性诊断、组合应用、恢复和刷新按钮回到原来的区域。

- 兼容样式仅处理长下拉框越界、中文字体回退、滚动标题尺寸跳变等问题，不改变上游网格、卡片尺寸或配色。

## 便携单文件启动提速

- 便携目标启用 `portable.useZip: true`。固定使用的 electron-builder 26.15.3 在此模式中通过 NSIS 的逐文件 zlib 压缩直接释放到当前启动的独立目录，省去旧 7z 路线的中间解压目录和整套文件复制。
- 保留 `unpackDirName: true` 对应的每次启动独立目录，退出后清理自己的目录；没有改为共享解压缓存，不会让第二次启动删除第一个实例正在使用的面板组件。
- 本机对照：旧 0.1.6 的两次独立解压启动为 13.94 / 13.96 秒；试验版为 4.66 / 4.74 秒，耗时减少约 66%。测量边界为启动便携封装至提取出的 Electron 探针读取版本并找到内置 F8 组件，不包含游戏扫描、系统冷启动或游戏加载时间。
- 代价是便携文件约从 299 MB 增至 381 MB（十进制）；安装版保留原压缩路线。
- 不修改杀毒设置，不删除组件，不变更用户数据存放位置。实际耗时仍受磁盘和系统扫描影响。
