# 早期界面与交互调整记录（2026-11-06）

这份文件保留当时以 0.1.2 命名的开发记录，不是最终发行说明。最终 0.1.2 的新增、优化与修复见 [发布说明](../RELEASE-NOTES.md)；其中档位页等早期设计已随后续开发调整。

- 设置中的扫描目录改为独立路径行，移除按钮固定在右侧，增加点击区域。移除仍只取消扫描记录，不删除磁盘文件。
- 游戏卡片适度放大，统一悬停工具栏与按钮样式。
- 游戏页恢复局部毛玻璃标题栏，去掉滚动容器顶部的细小露底缝隙，标题高度保持稳定。
- 详情封面支持横版素材回退，修复鸣潮、星穹铁道及其他非 Steam 素材仅显示文字占位的问题；已有自定义封面优先保留。图片服务失败不再阻断详情读取。
- 修复档位页“浏览并添加游戏目录”调用不存在接口的问题，复用已有目录选择流程，并显示失败原因。
- 详情页优先显示神经渲染模式、模型选择和补帧倍率；硬件模板、运行库组合、输入保护、组件版本、文件和日志按需展开。
- 保留运行时检测、版本锁定、变更预览和回滚；运行状态入口可直接跳转，发现冲突或日志异常时自动展开诊断。
- 缩短应用、导入和还原按钮，统一高度与排列；操作日志出现新内容时自动展开。

本次调整不修改游戏内插件、运行库、预设数值或配置格式；展开/折叠只影响管理器界面。

## 项目参考与后续方向

查阅日期：2026-11-06。以下是各项目公开文档中的设计与功能，未对其游戏性能进行实测。

| 项目 | 可参考的部分 | 对本分支的取舍 |
| --- | --- | --- |
| [Prism NR](https://github.com/ChefDavid0815/prism-nr/blob/main/README.md) | 将常用档位、实时帧时间、基础/输出帧率、1% low 和画面对比放在同一工作流；使用独立 Prism Core 运行时 | 本次借鉴配置分层。公开说明要求 RTX 50；不能据此认定可替换 RTX 40 上的现有运行时。性能对比和目标帧率自适应需要插件提供相应数据与控制接口。 |
| [RTX-FG-Manager](https://github.com/pandaligx/RTX-FG-Manager/blob/main/README.zh-CN.md) | 所选游戏、硬件、补丁及操作集中展示，每游戏配置独立，管理器与补丁分别更新 | 保留现有组件库、版本锁定与事务恢复；下一步优先让“当前值 / 待应用值”可直接比较，避免重新应用模板覆盖手动调校。 |
| [DLSS Swapper](https://github.com/beeradmoore/dlss-swapper/blob/main/README.md) | 多来源游戏库、DLSS / FSR / XeSS 文件版本管理与恢复 | 继续统一游戏卡片、详情页和组件库的数据来源；明确区分运行库版本、驱动预设与神经模型文件。 |
| [DLSS AiO Swapper](https://github.com/machiavelli31/DLSS-AiO-Swapper/blob/main/README.md) | 每游戏 SR/RR/FG 预设、驱动覆盖状态、组件来源与校验信息 | 可增加驱动覆盖只读检查，解释“磁盘已替换但游戏仍用另一版本”的情况。接入写入功能前须验证配置保存、恢复与不同 GPU 支持范围。 |

建议顺序：

1. **每游戏配置保存与差异预览**：展示当前值、修改值、模板来源及需要重启的项目，支持保存/恢复用户配置。
2. **有依据的性能对比**：只有采集到真实样本后才显示基础 FPS、输出 FPS、1% low、帧时间与 NR 开销；注明采样时长、场景及数据来源。插件缺少数据时明确说明，不能以倍率推算 1% low。
3. **驱动覆盖与依赖检查**：只读识别驱动覆盖，显示组件之间的适配约束、更新影响以及需要重启的游戏。
4. **兼容性经过验证后再扩展运行时**：Prism Core、自动工作分辨率和对比视图都需要单独验证 GPU、图形 API、插件接口及卸载恢复，不能作为普通 UI 更新直接替换进游戏。

Prism 的[设计规范](https://github.com/ChefDavid0815/prism-nr/blob/main/DESIGN.md)包含较强的动态效果。本分支继续采用静态布局和局部透明标题栏，以符合此前降低页面开销的要求。
