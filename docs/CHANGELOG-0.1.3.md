# 0.1.3 布局细节修正

- 神经渲染与多帧生成高级区采用紧凑折叠样式，常用的运行库组合、输入策略优先显示，文件版本与兼容说明放在下方。
- 两张卡片按内容各自展开，展开一侧时不再把另一侧拉出大片空白。
- 修复运行库组合移入折叠区后丢失输入框样式、长选项撑出卡片的问题。下拉框使用简短名称，完整版本及策略说明显示在下方，并随选择更新；保存的选项值不变。
- 目标游戏选择区缩短按钮文案并统一高度。宽窗口为一行，窄窗口自动分行，保留目录选择、导入模型、软件更新功能。
- 移除“查看运行状态与组件”跳转文字，保留原有运行时检测和组件清单。
- 游戏封面上的 DirectX 标签改为 DX12 / DX11 等短标签，完整名称保留在悬停提示中。标签与封面、目录、隐藏三个按钮对齐在顶部同一行。
- 三个操作按钮使用统一线条图标，保留悬停提示、键盘访问和原有行为；列表模式保留独立按钮列。

本次只调整管理器界面，不改变游戏插件、运行库文件、预设参数、版本锁定或回滚逻辑。

## 验证

- 在隔离用户目录和模拟游戏数据下验证实际 Electron 渲染器；覆盖两种风格、明暗主题、800–1500 像素窗口及 125% 页面缩放。
- 检查展开后的长文本与下拉框边界、单侧展开高度、卡片按钮与 API 标签位置、列表模式及目标游戏工具栏。
- 验证切换运行库/输入策略后的说明和提交参数一致，折叠状态与倍率选择保留；模型库、运行时检测、变更预览及版本锁定的现有交互通过检查。
- 本次没有修改游戏文件，没有进行游戏内帧率或画质测试。
