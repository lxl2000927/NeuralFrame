## 0.1.1 修复说明

- 历史页新增“清除历史记录”及确认框；仅清除操作记录，保留游戏备份、版本锁定与回滚数据。重开页面或重启软件不会从旧备份重新导入已清除记录。

- 移除设置中的社区通知和社区个人资料入口；未配置开发社区服务时，不再为旧的启用记录启动通知轮询。
- 修复便携版重复启动共用临时解压目录的问题，避免第二个实例退出后导致正在运行的管理器提示缺少 F8 面板插件。
- 修复运行时检测复选框显示文本光标的问题，并统一勾选类控件的鼠标样式。
- 神经模型文件库显示本地可用数量与未导入记录，新增“获取更多神经模型”入口，直达组件库的神经模型筛选。
- 返回档位页面时重新读取模型库，显示刚下载或导入的模型；软件更新按钮改为明确的“检查软件更新”。

随包神经模型仍为一个不同的 310.8.SF-v2 文件。上游目录中的 310.9.16-oct2026 使用相同 SHA-256，不应被算作第二个模型。DLSS SR / FG 运行库与神经模型分别管理，版本号不能混为一谈。

本次修改不更换游戏中的运行库、补帧插件或参数。版本锁定、变更预览、回滚和已适配的中文面板保留。

### 项目参考与后续方向

查阅日期：2026-11-06。以下是各项目公开文档中的设计与功能，未对其游戏性能进行实测。

| 项目 | 可参考的部分 | 对本分支的取舍 |
| --- | --- | --- |
| [Prism NR](https://github.com/ChefDavid0815/prism-nr/blob/main/README.md) | 将常用档位、实时帧时间、基础/输出帧率、1% low 和画面对比放在同一工作流；使用独立 Prism Core 运行时 | 本次借鉴配置分层。公开说明要求 RTX 50；不能据此认定可替换 RTX 40 上的现有运行时。性能对比和目标帧率自适应需要插件提供相应数据与控制接口。 |
| [RTX-FG-Manager](https://github.com/pandaligx/RTX-FG-Manager/blob/main/README.zh-CN.md) | 所选游戏、硬件、补丁及操作集中展示，每游戏配置独立，管理器与补丁分别更新 | 保留现有组件库、版本锁定与事务恢复；下一步优先让“当前值 / 待应用值”可直接比较，避免重新应用模板覆盖手动调校。 |
| [DLSS Swapper](https://github.com/beeradmoore/dlss-swapper/blob/main/README.md) | 多来源游戏库、DLSS / FSR / XeSS 文件版本管理与恢复 | 继续统一游戏卡片、详情页和组件库的数据来源；明确区分运行库版本、驱动预设与神经模型文件。 |
| [DLSS AiO Swapper](https://github.com/machiavelli31/DLSS-AiO-Swapper/blob/main/README.md) | 每游戏 SR/RR/FG 预设、驱动覆盖状态、组件来源与校验信息 | 可增加驱动覆盖只读检查，解释“磁盘已替换但游戏仍用另一版本”的情况。接入写入功能前须验证配置保存、恢复与不同 GPU 支持范围。 |

建议顺序：

1. **每游戏配置保存与差异预览**：展示当前值、修改值、模板来源及需要重启的项目，支持保存/恢复用户配置。
2. **有依据的性能对比**：只有采集到真实样本后才显示基础 FPS、输出 FPS、1% low、帧时间与 NR 开销；注明采样时长、场景及数据来源。插件缺少数据时明确说明，不能以倍率推算 1% low。
3. **驱动覆盖与依赖检查**：只读识别驱动覆盖，显示组件之间的适配约束、更新影响以及需要重启的游戏。
4. **兼容性经过验证后再扩展运行时**：Prism Core、自动工作分辨率和对比视图都需要单独验证 GPU、图形 API、插件接口及卸载恢复，不能作为普通 UI 更新直接替换进游戏。

Prism 的[设计规范](https://github.com/ChefDavid0815/prism-nr/blob/main/DESIGN.md)包含较强的动态效果。本分支继续采用静态布局和局部透明标题栏，以符合此前降低页面开销的要求。

### 便携单文件启动提速

- 便携目标启用 `portable.useZip: true`。固定使用的 electron-builder 26.15.3 在此模式中通过 NSIS 的逐文件 zlib 压缩直接释放到当前启动的独立目录，省去旧 7z 路线的中间解压目录和整套文件复制。
- 保留 `unpackDirName: true` 对应的每次启动独立目录，退出后清理自己的目录；没有改为共享解压缓存，不会让第二次启动删除第一个实例正在使用的面板组件。
- 本机对照：旧 0.1.6 的两次独立解压启动为 13.94 / 13.96 秒；试验版为 4.66 / 4.74 秒，耗时减少约 66%。测量边界为启动便携封装至提取出的 Electron 探针读取版本并找到内置 F8 组件，不包含游戏扫描、系统冷启动或游戏加载时间。
- 代价是便携文件约从 299 MB 增至 381 MB（十进制）；安装版保留原压缩路线。
- 不修改杀毒设置，不删除组件，不变更用户数据存放位置。实际耗时仍受磁盘和系统扫描影响。

## 0.1.8 · 轻量主程序与按需组件

- 从便携单文件与安装版移除完整离线模型、运行库和插件载荷，只保留主程序、F8 桥接、中文适配及许可文件。
- 首次应用按实际路线准备组件；单独启用 MFG 不下载神经渲染模型。关闭功能和恢复原始文件不依赖在线下载。
- 配套组件固定版本、地址、压缩包和文件 SHA-256。下载失败、取消或校验失败时不写入游戏，可重试。
- 提供下载进度和取消；准备缓存后重新生成应用前预览，继续校验版本锁定。
- 组件保存在 `%APPDATA%\dlss5-swapper-enhanced\component-library-v1\runtime`，跨软件版本复用。缓存完整时可离线应用，已有统一组件库按文件指纹复用。
- 插件页增加配套版本的下载 / 校验入口；模型下拉框区分本地可用和首次使用时下载。
- 保留现有布局、汉化、运行时检测、每游戏版本选择、锁定和回滚。

首次使用某项功能需要联网获取缺少的组件；启动和浏览页面不自动下载。Electron 运行环境仍随程序分发，所以主程序不会缩小到几 MB。

本版验证使用隔离配置和测试游戏目录，没有改动用户实际游戏文件。组件安装、缓存验证不代表游戏内画质或帧率验证。
